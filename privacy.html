プライバシーポリシー

取得する情報と利用目的

Midnight BGM Automation は、運営者が許可したチャンネルの名前・ID、動画の投稿情報、再生数・視聴時間などの集計データを取得します。これらは投稿先の確認、予約投稿、運営者向けの集計に使います。

保存と共有

認証情報と集計結果は運営者のMacに保存します。この公開ページには保存しません。Googleユーザーデータの販売、広告への利用、第三者への提供は行いません。Google APIから取得した情報の利用と移転は、Google API Services User Data Policyの限定使用要件に従います。

アクセス解除と削除

Googleアカウントの接続設定でアクセスを解除できます。運営者はMac上の認証ファイルと集計ファイルを削除できます。

連絡先

問い合わせはGoogleの同意画面に表示されるサポート窓口へお願いします。
